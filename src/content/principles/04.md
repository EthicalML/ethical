Production machine learning systems need the operational capability to diagnose problems and reproduce results. Teams should be able to restore a previous model version or reproduce an input when debugging specific behaviour.

Reproducibility depends on capturing the data, configuration and environment, and computational graph used at each step. Infrastructure and established ML operations practices should preserve those components across transformation pipelines.
