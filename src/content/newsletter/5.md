## [XAI - eXplainability library for AI](/open-source/xai/)

We are extremely excited to announce the launch of [XAI v0.0.2 ALPHA](/open-source/xai/), an open source library developed by [The Institute for Ethical AI & Machine Learning](https://ethical.institute/) focused on AI explainability. XAI is currently in very early stages, but we have very exciting plans for this project aligned with our [Responsible ML Principle #3](https://ethical.institute/principles.html#commitment-3). You can install it by running [`pip install xai`](https://pypi.org/project/xai/). You can also learn more about the principles that inspired this project at our [Tensorflow London meetup talk](https://www.youtube.com/watch?v=GZpfBhQJ0H4).

## [Deep neural inspection](https://medium.com/thewulab/deep-neural-inspection-with-deepbase-de3653257643)

One of our fellow readers suggested a very interesting paper which was presented at NeurIPS 2018: ["Deep Neural Inspection with DeepBase"](https://www.dropbox.com/s/abth7ko579cf9mu/dnn-nips19learnsys-cr.pdf?dl=0) (Thanks Cecilia Shao from CometML!). In this paper they propose a declarative system for developers to inspect and understand neural networks. They also provide a [great blog post](https://medium.com/thewulab/deep-neural-inspection-with-deepbase-de3653257643) where they provide 1) the definition of "deep neural inspection", 2) The inspection of a PacMan Agent with DeepBase, and 3) a link to all contributors. We would like to also point our readers to another very interesting approach to inspect DNNs presented in our [3rd newsletter edition](https://ethical.institute/mle/3.html), namely SHAP's [DeepLift approach](https://github.com/kundajelab/deeplift) towards explaining predictions.

## [AI against alzheimer's disease](https://pubs.rsna.org/doi/10.1148/radiol.2018180958)

A research team from the UCSF released [a paper which showed a deep learning model](https://pubs.rsna.org/doi/10.1148/radiol.2018180958) that achieved 100% sensitivity (i.e. no false negatives) and 82% specificity (i.e. low false positives) on an average of 6 years prior to final diagnosis. [A lot of media articles](https://www.ucsf.edu/news/2018/12/412946/artificial-intelligence-can-detect-alzheimers-disease-brain-scans-six-years) have also spread the word on this piece. Imaging has been an area in medicine that deep learning has been continuously excelling on, very exciting to see what 2019 has ahead, especially with the current breakthroughs in NLP.

## [Differential privacy for tensorflow](https://github.com/tensorflow/privacy)

In brief, differential privacy is a technique that allows for a variable level of statistical noise to be added to a dataset. This makes it harder for [re-identification attacks](https://en.wikipedia.org/wiki/Data_re-identification) (making sure privacy is protected), whilst keeping the statistical properties of the data for analysis to be carried out. This is awesome as it ensures data is not available in its raw form when not necessary, but can still be used for machine learning (Apple provides [a great definition](https://www.apple.com/privacy/docs/Differential_Privacy_Overview.pdf)). The Tensorflow team has created [a new open source library](https://github.com/tensorflow/privacy) that includes implementations of TensorFlow optimizers for training machine learning models with differential privacy.

## [The role of ML in databases](https://rise.cs.berkeley.edu/blog/what-is-the-role-of-machine-learning-in-databases/)

Incredibly [interesting article](https://rise.cs.berkeley.edu/blog/what-is-the-role-of-machine-learning-in-databases/) by UC Berkeley's Rise Lab on the ML and databases discussion, as well as their recently updated paper, "[Learning to Optimize Join Queries With Deep Reinforcement Learning](http://zongheng.me/pubs/dq-jan-2019.pdf)”. In this post they cover how they integrated a form of Deep Q-Learning approach into full-featured query optimizers with minimal modification, achieving signfiicant results.

## [MLOps = ML Operations](https://github.com/EthicalML/awesome-machine-learning-operations)

This week's edition is focused on ETL and data pipeline frameworks which fall on our [Responsibel ML Principle #4](https://ethical.institute/principles.html#commitment-4). The four featured libraries this week from the [Awesome MLOps list](https://github.com/EthicalML/awesome-machine-learning-operations) are:

- [Apache Airflow](https://airflow.apache.org/) - Data Pipeline framework built in Python, including scheduler, DAG definition and a UI for visualisation
- [Luigi](https://github.com/spotify/luigi) - Luigi is a Python module that helps you build complex pipelines of batch jobs, handling dependency resolution, workflow management, visualisation, etc
- [Genie](https://github.com/Netflix/genie) - Job orchestration engine to interface and trigger the execution of jobs from Hadoop-based systems
- [Oozie](http://oozie.apache.org/) - Workflow scheduler for Hadoop jobs

If you know of any libraries that are not in the ["Awesome MLOps"](https://github.com/EthicalML/awesome-machine-learning-operations) list, please do give us a heads up or feel free to [add a pull request](https://github.com/EthicalML/awesome-machine-learning-operations)!
