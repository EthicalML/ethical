## [Machine Learning Michaelangelo](https://towardsdatascience.com/doing-machine-learning-the-uber-way-five-lessons-from-the-first-three-years-of-michelangelo-da584a857cc2)

In-house development of end-to-end machine learning orchestration frameworks is a trend for tech companies. A few months ago, Uber released [an article](https://towardsdatascience.com/doing-machine-learning-the-uber-way-five-lessons-from-the-first-three-years-of-michelangelo-da584a857cc2) where they share key lessons learned from the first 3 years working with their in-house machine learning framework "Michaelangelo". Michaelangelo is an awesome example of machine learning operations. If you are curious and wish to know more about it, here is an in-depth [article that introduces Michaelangelo](https://eng.uber.com/michelangelo/) and here is a [video that provides an overview](https://www.youtube.com/watch?v=hGy1cM7_koM).

## [The new role of data engineers](https://blog.fishtownanalytics.com/does-my-startup-data-team-need-a-data-engineer-b6f4d68d7da9)

The role of the data engineer as we've known it is changing rapidly. This [FishTown Analytics article](https://blog.fishtownanalytics.com/does-my-startup-data-team-need-a-data-engineer-b6f4d68d7da9) provides a great insight on how new tools are automating the "boring parts" of data engineering, enabling for focus on higher-level more important tasks. Interesting first hand overview of what will be an incredibly fast evolving role in the next few years.

## [Why data scientists love MLOps](https://opensource.com/article/19/1/why-data-scientists-love-kubernetes)

An interesting [perspective from opensource.com](https://opensource.com/article/19/1/why-data-scientists-love-kubernetes) where they argue why data scientists like MLOps, and more specifically, Kubernetes. The article covers fundamentals of ["Principles 4 - reproducibility"](https://ethical.institute/principles.html#commitment-4) and how MLOps tools like Kubernetes allows data scientists to focus on the more important tasks, whilst being able to [perform work at scale](https://mybinder.org) without much complexities. There is also [a great accompanying video](https://www.youtube.com/watch?v=frQeK8xo9Ls) covering the concepts in the article. If you are curious to extend your knowledge and learn some DevOps fundamentals, here is a great tutorial that teaches ["enough docker to be useful".](https://towardsdatascience.com/learn-enough-docker-to-be-useful-b7ba70caeb4b)

## [Seeing theory: Probability & stats](https://seeing-theory.brown.edu)

Really awesome (and visually pleasing) introduction to probability and statistics. ["Seeing theory"](https://seeing-theory.brown.edu) is a short course that introduces basic probability, compound probability, probability distributions, frequentist inference, bayesian inference and regression analysis. Kudos to Daniel Kunin from Brown University for such a great interactive course.

## [Data Science vs Engineering](https://blog.dominodatalab.com/data-science-vs-engineering-tension-points/)

Incredibly [insightful discussion](https://blog.dominodatalab.com/data-science-vs-engineering-tension-points/) about the friction between software engineering, data science and data engineering teams in industry. The article summarises a panel conversation between several professionals in this field, and covers some of the main challenges that teams face where these different professions intersect. It covers key points around collaboration, tension points, ownership, mindset, communication and training. It also covers some core differences between academia and industry. This last point is especially interesting, as there has been some tension in scientific conferences between data science and engineering, and more specifically when a breakthrough of the latter is also considered one of the former. The discussion in [the review of a recent paper submitted for ICLR 2019](https://openreview.net/forum?id=HJxpDiC5tX) provides an interesting insight on this.

## [Accelerate ML with Batch Norm](https://machinelearningmastery.com/how-to-accelerate-learning-of-deep-neural-networks-with-batch-normalization/)

Machine Learning Mastery comes back this week with yet another great hands on tutorial. This week Jason provides an insight on how to [Accelerate Learning of Deep Neural Networks With Batch Normalization](https://machinelearningmastery.com/how-to-accelerate-learning-of-deep-neural-networks-with-batch-normalization/). This tutorial includes an overview of how to create and configure a BatchNormalisation layer using the Keras API, how to add the layer to a deep learning model, and how to update a model to use batch normalisation to accelerate training on a binary classification problem.

## MLOps = [Featured OS Libraries](https://github.com/EthicalML/awesome-machine-learning-operations)

This week's edition is focused on privacy preserving machine learning frameworks which fall on our [Responsibel ML Principle #7](https://ethical.institute/principles.html#commitment-7). The four featured libraries this week from the [Awesome MLOps list](https://github.com/EthicalML/awesome-machine-learning-operations) are:

- [Tensorflow Privacy](https://github.com/tensorflow/privacy) - A Python library that includes implementations of TensorFlow optimizers for training machine learning models with differential privacy.
- [TF-Encrypted](https://github.com/mortendahl/tf-encrypted) - A Python library built on top of TensorFlow for researchers and practitioners to experiment with privacy-preserving machine learning.
- [PySyft](https://github.com/OpenMined/PySyft) - A Python library for secure, private Deep Learning. PySyft decouples private data from model training, using Multi-Party Computation (MPC) within PyTorch.
- [Uber SQL Differencial Privacy](https://github.com/uber/sql-differential-privacy) - Uber's open source framework that enforces differential privacy for general-purpose SQL queries.

If you know of any libraries that are not in the ["Awesome MLOps"](https://github.com/EthicalML/awesome-machine-learning-operations) list, please do give us a heads up or feel free to [add a pull request](https://github.com/EthicalML/awesome-machine-learning-operations)!
