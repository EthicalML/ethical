## [Production-level AI Explanations](https://github.com/SeldonIO/seldon-core/tree/master/examples/explainers/alibi_anchor_tabular)

We have put together an [end-to-end tutorial](https://github.com/SeldonIO/seldon-core/tree/master/examples/explainers/alibi_anchor_tabular) to showcase how to deploy a production ML model, and then leverage some of the black box model AI interpretation techniques in the [Alibi library](https://github.com/seldonio/alibi) to provide an interface for production-level explanations. This design pattern allows you to deploy a black box income classifier model together with another model running in parallel that is able to explain why that initial model made the predicctions it has made. The technique used to reverse-engineer and interpret preictions is "[Anchor explanations](https://docs.seldon.io/projects/alibi/en/v0.2.2/examples/anchor_tabular_adult.html)" which basically answers the question of "what are the features in this inference request that influenced the prediction the most?".

## [85% of Big Data Projects Fail](https://www.techrepublic.com/google-amp/article/85-of-big-data-projects-fail-but-your-developers-can-help-yours-succeed/)

Excellent (albeit brief) article outlining the failure rate of big data (hadoop-related) projects. With a staggering 85%, it is clear how important it is to make sure the success criteria is well set from the beginning to avoid failure of projects. Although it is necessary to ensure companies are able to run internal POCs (proof-of-concepts or Pilots), it is also critical to make sure that the path is planned for the organisation to be able to support production-ready adoptions of these big data projects.

## [ML Mastery on building GANs](https://machinelearningmastery.com/how-to-develop-a-generative-adversarial-network-for-a-cifar-10-small-object-photographs-from-scratch/)

Machine learning mastery comes back this week with an [excellent tutorial](https://machinelearningmastery.com/how-to-develop-a-generative-adversarial-network-for-a-cifar-10-small-object-photographs-from-scratch/) that dives into GANs, and covers three key areas: 1) How to define and train the standalone discriminator model for learning the difference between real and fake images. 2) How to define the standalone generator model and train the composite generator and discriminator model. 3)How to evaluate the performance of the GAN and use the final standalone generator model to generate new images.

## OSS: [Adversarial Robustness](https://github.com/EthicalML/awesome-production-machine-learning#adversarial-robustness-libraries)

The theme for this week's featured ML libraries is once again [Adversarial Robustness](https://github.com/EthicalML/awesome-production-machine-learning#adversarial-robustness-libraries), which includes tools for adversarial attacks and adversarial security. These libraries are an incredibly exciting addition that fall in our [Responsible ML Principle #8](https://ethical.institute/principles.html#commitment-8), and the whole section was contributed by one of the Fellows at the Institute [Ilja Moisejevs](https://www.linkedin.com/in/moisejev/) from Calipso AI. The four featured libraries this week are:

- AdverTorch - library for adversarial attacks / defenses specifically for PyTorch.
- [TextFool](https://github.com/bogdan-kulynych/textfool) - plausible looking adversarial examples for text generation.
- [DEEPSEC](https://github.com/kleincup/DEEPSEC) - another systematic tool for attacking and defending deep learning models.
- [Artificial Adversary](https://github.com/airbnb/artificial-adversary) - AirBnB's library to generate text that reads the same to a human but passes adversarial classifiers.

If you know of any libraries that are not in the ["Awesome MLOps"](https://github.com/EthicalML/awesome-machine-learning-operations) list, please do give us a heads up or feel free to [add a pull request](https://github.com/EthicalML/awesome-machine-learning-operations)!
