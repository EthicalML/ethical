## [Combat Imbalanced Classes](https://machinelearningmastery.com/tactics-to-combat-imbalanced-classes-in-your-machine-learning-dataset/)

8 Tactics to Combat Imbalanced Classes in Your Machine Learning Dataset. Very comprehensible article providing some of the best practices when approaching class imbalance.

## [Compliant machine learning](https://www.youtube.com/watch?v=eOzl-LFqYFM)

Great video that discusses the challenges of [explainability](https://ethical.institute/principles.html#commitment-3) and [reproducibility](https://ethical.institute/principles.html#commitment-4) in production machine learning. It provides an abstraction of production machine learning into a compliant pipeline at each computational step. It is presented with an example using [Pachyderm](https://github.com/pachyderm/pachyderm) for the "compliant" pipeline, and [Seldon](https://github.com/SeldonIO/seldon-core) for serving the production model.

## [Data science career transitions](https://towardsdatascience.com/3-common-data-science-career-transitions-and-how-to-make-them-happen-588c3618942f)

"What got people hired back in 2017 doesn’t work today, and the disparity between data science hiring standards today and those that will apply one or two years from now will probably be even bigger". This article provides an interesting path to approach a career change into data science coming from 3 angles: complete beginners, software engineers, and recent STEM grads.

## [Curiousity driven data science](https://hbr.org/2018/11/curiosity-driven-data-science)

This article proposes that it's possible to introduce a culture of innovation by empowering data scientists through their innate curiousity. It covers: 1) ensure data science is its own entity within an organisation, 2) equip data scientists with the right tools, and 3) build a culture that supports a process for learning and experimentation

## [Automate boring tasks](https://towardsdatascience.com/python-and-slack-a-natural-match-60b136883d4d)

Awesome piece based on the "[automate your boring stuff](https://automatetheboringstuff.com/)" book + [Slacker](https://github.com/os/slacker), an open source Python library to interact with Slack. The article provides examples of how they super-charged ML workflows

## [Facebook open sources PyText](https://code.fb.com/ai-research/pytext-open-source-nlp-framework/)

Facebook open sources "a modeling framework that blurs the boundaries between experimentation and large-scale deployment." It's based on PyTorch, and provides a set of classifiers, sequence taggers, etc. ([GitHub Repository)](https://github.com/facebookresearch/pytext)

## [MLOps = ML Operations](https://github.com/EthicalML/awesome-machine-learning-operations)

Our Awesome Machine Learning Operations list has seen some great contributions these last few days. This edition's featured open source libraries focus majorly around [reproducibility](https://ethical.institute/principles.html#commitment-4), and include:

- [MLFlow](https://github.com/mlflow/mlflow) - Open source platform to manage the ML lifecycle, including experimentation, reproducibility and deployment.
- [Sacred](https://github.com/IDSIA/sacred) - Tool to help you configure, organize, log and reproduce machine learning experiments.
- [FGLab](https://github.com/Kaixhin/FGLab) -Machine learning dashboard, designed to make prototyping experiments easier.
- [StudioML](https://www.studio.ml) - Model management framework which minimizes the overhead involved with scheduling, running, monitoring and managing artifacts of your machine learning experiments.

If you know of any libraries that are not in the list, please do give us a heads up or feel free to [add a pull request](https://github.com/EthicalML/awesome-machine-learning-operations)!
