## [Programming Explainable ML](https://medium.com/@BonsaiAI/what-do-we-want-from-explainable-ai-5ed12cb36c07)

One of the best insights on practical approaches towards explainable machine learning by Mark Hammond, former founder at Bons.AI and current director of business AI at microsoft. Mark provides 3 key categories that tackle the question of explainability: Deep Explanation, Model Induction and Machine Teaching. The last one being key - namely combining machine learning with subject matter expertise (aka [Principle #3 "Explainability by Justification"](https://ethical.institute/principles.html#commitment-3) in our [Principles for Responsible ML](https://ethical.institute/principles.html) 🤖).

## [Beyond Accuracy with ROCs](https://machinelearningmastery.com/roc-curves-and-precision-recall-curves-for-classification-in-python/)

One of our core principles advocates for statistical metrics that go beyond beyond accuracy ([Principle #6](https://ethical.institute/principles.html#commitment-6)). ROC curves and precision-recall curves are great tools to open up a model and assess its performance. [This machine learning mastery blog post](https://machinelearningmastery.com/roc-curves-and-precision-recall-curves-for-classification-in-python/) provides a great overview of key concepts including [ROC Curves](https://en.wikipedia.org/wiki/Receiver_operating_characteristic), [Precision and Recall](https://en.wikipedia.org/wiki/Precision_and_recall) + More!

## [Super-SlowMo Generators](https://people.cs.umass.edu/~hzjiang/projects/superslomo/)

NVIDIA comes back thanks to a [community PyTorch implementation](https://github.com/avinashpaliwal/Super-SloMo) of their paper: "[Super SloMo: High Quality Estimation of Multiple Intermediate Frames for Video Interpolation"](https://people.cs.umass.edu/~hzjiang/projects/superslomo/). They use deep learning video interpolation techniques to generate intermediate frames, resulting in ultra-slowmo videos.

We are thrilled to announce that the European Commission has launched [the draft of the AI Ethics Guidelines](https://ec.europa.eu/digital-single-market/en/news/draft-ethics-guidelines-trustworthy-ai) produced by the European Commission’s High-Level Expert Group on Artificial Intelligence (AI HLEG), which The Institute for Ethical AI & Machine Learning is currently part of. ## [MLOps = ML Operations](https://github.com/EthicalML/awesome-machine-learning-operations)

A new section to the Machine Learning operations list specifically around [Explainability of Predictions](https://github.com/EthicalML/awesome-machine-learning-operations) (aka [Principle #3](https://ethical.institute/principles.html#commitment-3)) - we are very excited about this new addition. The machine learning explainability libraries we're showcasing this week are:

- [SHAP](https://github.com/slundberg/shap) - SHapley Additive exPlanations is a unified approach to explain the output of any machine learning model.
- [LIME](https://github.com/marcotcr/lime) - Local Interpretable Model-agnostic Explanations for machine learning models.
- [ELI5](https://github.com/TeamHG-Memex/eli5) - "Explain Like I'm 5" is a Python package which helps to debug machine learning classifiers and explain their predictions.
- [Tensorboard's What-If](https://pair-code.github.io/what-if-tool/) - Tensorboard screen to analyse the interactions between inference results and data inputs.

If you know of any libraries that are not in the ["Awesome MLOps"](https://github.com/EthicalML/awesome-machine-learning-operations) list, please do give us a heads up or feel free to [add a pull request](https://github.com/EthicalML/awesome-machine-learning-operations)!
