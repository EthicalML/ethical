## [Bias and Explainability in ML](https://www.youtube.com/watch?v=rq95qznOZKw)

A [deep dive on algorithmic bias and explainability](https://www.youtube.com/watch?v=rq95qznOZKw) in data and machine learning using the [XAI Library](https://github.com/EthicalML/XAI). This video provides a case study automating a loan aproval process to show how undesired bias can be introduced throughout the process. The talk also covers how these undesired biases can be tackled using open source tools, together with a three step process consisting of 1) data analysis, 2) model evaluation and 3) production monitoring.

## [Federated Learning with PyTorch](https://blog.openmined.org/upgrade-to-federated-learning-in-10-lines/)

[Great practical tutorial](https://blog.openmined.org/upgrade-to-federated-learning-in-10-lines/) to introduce federated learning using the [PySift Library](https://github.com/OpenMined/PySyft) to distribute a MINST deep learning task across multiple devices. Federated learning is a method that allows for machine learning models to be trained across multiple edge devices in the network instead on a central server, which we covered [a few weeks ago](https://ethical.institute/mle/9.html).

## [Data Visualisation Deep Dive](https://socviz.co/)

Really awesome [free e-book](https://socviz.co/) on all-things data visualisation using R. This very comprehensible resource introduces best practices in data analysis, R usage, data transformation, colour/display selection, graph usage, models, maps and more (much more). You can also buy a hard copy in amazon to support the cause.

## [Practical recommenders tutorial](https://github.com/Microsoft/Recommenders)

Hands on [end-to-end tutorial on recommender systems](https://github.com/Microsoft/Recommenders) that dives into the movie dataset. It follows a [CRISP-DM](https://en.wikipedia.org/wiki/Cross-industry_standard_process_for_data_mining)-like process to explain every stage in the model developing stage (e.g. data understanding, preparation, etc). The tutorial covers fundamental concepts in recommender systems such as explicit/implicit feedback and dives into practical examples implementing Collaborative Filtering (ALS), Neural Collaborative Filtering, Restricted Boltzman Machine, Smart Adaptive Recommendations, Surprise SVD and Vowpal Wabbit.

## [Learning Curves in ML evaluation](https://machinelearningmastery.com/learning-curves-for-diagnosing-machine-learning-model-performance/)

Learning curves are a fundamental technique to evaluate machine learning models. Machine learning mastery brings us [a gentle introduction to learning curves](https://machinelearningmastery.com/learning-curves-for-diagnosing-machine-learning-model-performance/) to diagnoes machine learning model performance. It provides an introduction to learning curves, an example on how to implement them, and an overview on how to read the graphs to diagnose an underfit, overfit or a well-fit model.

## [Machine Learning Cybersecurity](https://www.oreilly.com/ideas/you-created-a-machine-learning-application-now-make-sure-its-secure)

It is common to hear machine learning applications to cybersecurity, but it's also critical to dive into the cybersecurity applications in machine learning. This [great post in the O'Reilly blog](https://www.oreilly.com/ideas/you-created-a-machine-learning-application-now-make-sure-its-secure) provides an overview of the flavours in which vulnerabilities can appear in machine learning model development, together with a few conceptual steps to take into account when taking into consideration machine learning development security.

## MLOps = [Featured OS Libraries](https://github.com/EthicalML/awesome-machine-learning-operations#12-function-as-a-service-frameworks)

We are excited to see the [Awesome MLOps](https://github.com/EthicalML/awesome-machine-learning-operations) list growing to almost 300 stars now! Thanks to everyone for your support! This week's edition is focused on new libraries on Data Storage Optimisation which fall on our Responsible ML Principle [#4](http://ethical.institute/principles.html#commitment-4). The four featured libraries this week are:

- [Alluxio](https://www.alluxio.org/docs/1.8/en/Overview.html) - A virtual distributed storage system that bridges the gab between computation frameworks and storage systems.
- [EdgeDB](https://edgedb.com/) - NoSQL interface for Postgres that allows for object interaction to data stored.
- [BayesDB](http://probcomp.csail.mit.edu/software/bayesdb/) - Database that allows for built-in non-parametric Bayesian model discovery and queryingi for data on a database-like interface
- [Apache Arrow](https://arrow.apache.org/) - In-memory columnar representation of data compatible with Pandas, Hadoop-based systems, etc

If you know of any libraries that are not in the ["Awesome MLOps"](https://github.com/EthicalML/awesome-machine-learning-operations) list, please do give us a heads up or feel free to [add a pull request](https://github.com/EthicalML/awesome-machine-learning-operations)!
