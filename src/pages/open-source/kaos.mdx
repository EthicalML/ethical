KAOS is a control plane for autonomous agents that need to use tools, credentials, budgets, and time without escaping accountable human boundaries.

<Feature title="Bounded agency by design" widget="kaos-graph">

Each agent receives only the authority required for its task. Planning, execution, policy checks, verification, and audit remain visible as work moves through the system.

The graph is not a decorative workflow: it represents explicit control points where teams can constrain or interrupt autonomous behaviour.

</Feature>

## Capabilities

KAOS treats safety controls as runtime infrastructure rather than guidance attached after deployment. The capability model stays in a shared data file because it is genuinely tabular and reused by the designed table.

## Build with bounded autonomy

Agent systems should become more useful without becoming less governable. KAOS gives engineering teams a small set of enforceable primitives for building that boundary into the platform.
