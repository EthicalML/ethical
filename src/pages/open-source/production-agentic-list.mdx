## Explore the categories

Seven sections cover the stack an agentic application needs in production: the frameworks that orchestrate agents, the observability that makes their behaviour legible, the protocols they speak to each other and to tools, the memory that carries context between runs, the security tooling that red teams them, the prompt engineering platforms behind their instructions, and the interfaces people meet them through.

## How it stays current

New libraries are added continuously and summarised in monthly releases, so watching the repository doubles as a changelog for the agent tooling ecosystem. It is the agentic sibling of [Awesome Production Machine Learning](/open-source/production-ml-list/), and the weekly companion to both is the Machine Learning Engineer newsletter.

The on-domain catalogue above is a committed rendition of the canonical GitHub README. The [GitHub repository](https://github.com/EthicalML/awesome-production-agentic-systems) remains the source of truth for updates and contributions.
