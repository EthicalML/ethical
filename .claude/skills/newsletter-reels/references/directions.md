Each direction names the MECHANISM the film acts out, in one line, and the five per topic show off different capabilities. Write new ones for every article; this file is the catalogue of what has been tried and what won.

Capabilities to rotate through: force-directed or 3D graph, infinite zoom, UI simulation (terminal, Slack, GitHub PR), particles to order, blueprint draw-on, data viz as sport, oscilloscope/HUD, Swiss kinetic type, 3D terrain flythrough, leaderboard tower, isometric exploded architecture, counter avalanche, cut-paper explainer, layered parallax, one transforming object, scaling-law sculpture, mechanical sorting machine, hand-drawn notebook, infinite wall.

## 1-netflix-knowledge-graph (Netflix red #E50914 accent, black ground)
- **1a Network graph collapse (force-directed 3D graph):** 6 tool islands (Atlas, Radar, incident.io, PagerDuty, Spinnaker, Slack) each holding a node for the same thing under different names ("application", "service", "cluster") drift as separate constellations; edges snap, the three names fuse into ONE glowing ops:Application node and the islands lock into a single knowledge graph, which AutoRCA agents then walk.
- [PICKED] **1b Infinite zoom (vector-crisp nested zoom):** start on a stylised Netflix home screen row whose render bar is "+1.5s slower"; zoom into the slow tile to find the services, into one service to find the graph, into one node to find a triple (subject - predicate - object), into the triple to find the answer.
- **1c Live terminal + Slack sim (UI simulation):** a chaotic incident Slack channel scrolls (200 messages, 50 people, 15 services), messages are lifted out one by one and typed into strict triples in a terminal; a SPARQL query runs and returns the same answer twice; AutoRCA posts a ranked hypothesis with its evidence.
- **1d Entropy ladder (particles to order, generative):** a storm of noisy particles (logs, alerts, chat) falls down a 5-rung ladder; each rung is a type-system gate that only lets correctly shaped particles through, so the bottom is a crisp deterministic lattice - "the right needle, not any needle".
- **1e Blueprint draw-on (technical line drawing):** an engineering blueprint inks itself: the ontology schema, the 12 namespaces as rooms, the catalog of ~49,000 entries as a gate, dimension callouts and mono annotations, ending with the agents stamped on top.

## 3-anthropic-code-review (Claude orange #D97757, cream #F5F0E8, ink)
- [PICKED] **3a GitHub PR sim (UI simulation):** a faithful PR page; Claude verifies its own work (checks tick green), several reviewer agents comment in parallel, a vote meter fills and only agreed findings post; a risk-tier badge decides human approvals (none / one / two); merge.
- **3b Exploded pipeline (isometric 3D architecture):** 7 stacked layers (verify, AI review, security, CI, risk-tier approval, merge queue + flags, rollback) disassemble like an exploded engine; a PR packet travels through each layer, getting stamped.
- **3c Counter avalanche (data-viz morph):** 2,500 changes/day become a stream of tiles that grows to 30,000; tiles sort themselves into risk tiers; merged PRs x2 and reverts -40% become the two bars that the tiles finally form.
- **3d Paper explainer (Vox-style cut paper, halftone, motion on twos):** hand-made paper cards, a paper human and paper robots, "did a human read the code?" crossed out, replaced by "what could go wrong, and which check catches it?".
- **3e Layered velocities (parallax motion design):** many layers move at different speeds and directions: a fast river of PRs in front, review agents drifting in the middle, giant outlined words ("RISK", "UNDO") slowly behind; pieces lock together on the beat into the risk-tier diagram.

## 4-meta-gem (Meta blue #0866FF, deep navy, white)
- **4a One transforming object (particles, three.js):** one cloud of tens of thousands of particles is the central GEM model; it starts as three separate surface blobs (Facebook, Instagram, Reels) that merge into one, then sheds knowledge into hundreds of small vertical models orbiting it.
- **4b Scaling-law sculpture (3D data viz):** a power-law curve of quality vs sequence length extruded into a glowing 3D surface; larger models ride a steeper ridge; 2.5x complexity, 18.9% conversions and 12% CTR as extruded numerals.
- **4c Speculative precompute (systems animation):** a timeline where Solaris precomputes user-ad embeddings in the background before the request arrives, borrowed from speculative decoding; requests arrive and find the answer already waiting; then the training numbers (FLOPs 4x, MFU 20-25%).
- [PICKED] **4d Exploded architecture (Kunlun, technical 3D):** the model block opens into its layers (attention, summarisation, cross interaction) with a user-behaviour sequence flowing through; then the many vertical models.
- **4e Kinetic numbers poster (typography + counters):** giant counters ARE the objects: 18.9% -> 12% -> 2.5x -> 4x -> 20-25%, each number morphs into the next with shape tweening, brand blue fields flipping.

## 5-larson-small-change (warm off-white #F4EFE6, ink, accent green #2BA84A for passed checks, red only for failures)
- [PICKED] **5a Sorting machine (mechanical toy, 3D or 2.5D):** PRs ride a conveyor through eligibility gates (<1,000 lines, no p1/p2 findings, 10+ merged PRs per service, no shared libraries); 10% drop into the fast "small-change" chute where an approve-only stamp hits; the rest go to human review.
- **5b GitHub check sim (UI simulation):** a PR page with a "small-change" GitHub check that CI decides, a Slack reacji pops, the review skill shows only two buttons: Approve / Ignore (never comment).
- **5c Dashboard chart story (data viz):** PRs per engineer 4x rising, incidents -42%, critical -78%, but review time line 33 -> 77 minutes going the wrong way; the tension resolves into the small-change lane.
- **5d Hand-drawn notebook (sketch / marker style, on twos):** a hand-drawn engineering notebook page, doodles and arrows, "meat proxy review" as a funny doodle of people proxying agents; Will Larson's "Maybe forever." in handwriting.
- **5e Infinite PR wall (layered 3D, parallax):** an endless wall of PRs flying past (4x volume, some engineers 10x and 25x); one lane lights up as the small-change fast lane; the camera rides it to the end card.
