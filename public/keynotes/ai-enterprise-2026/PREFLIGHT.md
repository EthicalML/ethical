# Presentation preflight

Run the production build and `npm run verify` before presenting. Wait for the opening loader to finish; all 3D models and source images are prepared before the first slide.

- Arrow keys or Page Down / Page Up advance and reverse. Click, Space and Enter advance.
- G opens the index; P opens speaker notes; F toggles fullscreen; B blanks the screen.
- Up / Down move between chapters.
- Original slide text and speaker notes remain in presenter view.
- Case-study numbers and forecasts come from the supplied presentation and are not newly verified.
- Reduced-motion settings keep the layout and content while disabling movement.
